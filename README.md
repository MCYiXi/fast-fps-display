# Fast FPS Display

一个轻量级的Minecraft模组，用于在屏幕左上角实时显示帧率。

## ✨ 功能特性

- 🔢 实时帧率显示（每秒更新）
- 🎨 智能颜色指示（绿/黄/红）
- ⚙️ 完全可配置（位置、背景、颜色）
- 🎮 游戏内命令控制
- 📱 支持所有游戏界面显示
- ⚡ 极低性能开销

## 🛠️ 系统要求

- Minecraft 1.20.1
- Fabric Loader 0.14.0+
- Fabric API 0.91.0+
- Java 17+

## 📥 安装

### 手动安装
1. 下载最新版本的 `.jar` 文件
2. 放入 `.minecraft/mods/` 文件夹
3. 启动游戏

### 开发者构建
```bash
# 克隆仓库
git clone https://github.com/MCYiXi/fast-fps-display.git

# 构建模组
./gradlew build

# 构建产物在 build/libs/
